# Training Platform

React + TypeScript + Vite + Tailwind CSS front-end.

## Develop
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Environment variables (all optional)
See `.env.example`. Without them the app runs in mock mode.

## Deploy
Import the repo in Vercel. Settings are in `vercel.json`
(Vite preset, `dist` output, SPA rewrite for client-side routing).
